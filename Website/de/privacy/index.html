Die App

Was sie speichert, und wo

  • Deine GitHub-Anmeldedaten (ein Zugriffstoken) werden im Schlüsselbund deines Geräts gespeichert. Wenn du die App auf mehr als einem deiner Geräte verwendest, werden sie im iCloud-Schlüsselbund gespeichert, damit alle angemeldet bleiben; Apple verschlüsselt sie Ende-zu-Ende.
  • Eine Kopie deiner Projekte und Issues sowie deiner GitHub-Mitteilungen zu Issues und Pull Requests (der Eingang) wird in einer Datenbank auf deinem Gerät gespeichert, damit die App sofort öffnet und offline funktioniert.
  • Einträge im Eingang, die du zurückgestellt oder als ungelesen markiert hast, und ob du ein fälliges Issue gelesen oder archiviert hast, werden im Key-Value-Speicher von iCloud in deinem Apple Account gespeichert, damit deine Geräte übereinstimmen; GitHub bietet dafür keinen Platz. Sie enthalten die Nummer der Mitteilung auf GitHub (oder die ID des Issues und den Tag, an dem es fällig war) und Datumsangaben, sonst nichts, und werden nach 30 Tagen entfernt. Nur du und deine Geräte können sie lesen.
  • Einstellungen wie das Erscheinungsbild, das App-Symbol, die Reihenfolge der Listenabschnitte und die Uhrzeit der Erinnerungen bleiben auf deinem Gerät.
  • Erinnerungen an fällige Issues sind Mitteilungen, die dein Gerät selbst anhand der synchronisierten Fälligkeitsdaten plant. Sie werden nirgendwohin gesendet, und wenn du sie in den Einstellungen ausschaltest, werden sie entfernt.

Was sie sendet, und an wen

  • Die App kommuniziert ausschließlich mit GitHub: mit api.github.com, um deine Projekte, Issues und Mitteilungen zu lesen und zu ändern, mit github.com während der Anmeldung und mit den Bildservern von GitHub für Avatare und Bilder in Issue-Beschreibungen. GitHub ist der Dienst, bei dem du dich anmeldest; was GitHub mit deinen Daten tut, beschreibt die Datenschutzerklärung von GitHub.
  • Zurückgestellte und ungelesene Einträge im Eingang gehen über Apple an deinen iCloud-Account, wie oben beschrieben.
  • Deine Anmeldedaten werden an niemanden außer GitHub gesendet.
  • Nichts wird an den Entwickler oder an Dritte gesendet. Die App enthält keinen Code für Analyse, Werbung oder Absturzberichte.
  • Wenn du in den Einstellungen deines Geräts Mit App-Entwicklern teilen aktiviert hast, gibt Apple anonyme Absturzberichte weiter. Das ist eine Funktion von Apple und liegt in deiner Hand, unter Einstellungen › Datenschutz & Sicherheit › Analyse & Verbesserungen.

Beispieldaten

„Mit Beispieldaten ausprobieren“ zeigt erfundene Projekte, die nur auf deinem Gerät gespeichert sind. Nichts, was du dort tust, wird irgendwohin gesendet.

Deine Daten löschen

Abmelden entfernt die Kopie deiner Projekte, Issues und Mitteilungen vom Gerät. Überall abmelden entfernt außerdem deine Anmeldedaten aus dem iCloud-Schlüsselbund, wodurch alle deine Geräte abgemeldet werden. Wenn du die App löschst, wird alles entfernt, was sie gespeichert hat. Deine Projekte und Issues selbst liegen auf GitHub und bleiben dort.
