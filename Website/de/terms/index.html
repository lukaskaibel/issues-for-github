Nutzungsbedingungen

Issues ist kostenlos. Diese Bedingungen gelten für die App und diese Website; sie sind kurz, weil die App kaum mehr tut, als anzuzeigen und zu ändern, was du ohnehin auf GitHub hast.

Die Lizenz

Issues aus dem App Store wird dir unter Apples Licensed Application End User License Agreement (der Standard-EULA) lizenziert. Die folgenden Punkte ergänzen die Standard-EULA, ersetzen sie aber nicht; wo sie voneinander abweichen, gilt die Standard-EULA.

Dein GitHub-Account

Du meldest dich mit deinem eigenen GitHub-Account an, und die App handelt in deinem Auftrag: Was du in ihr tust, geschieht auf GitHub unter deinem Namen, als hättest du es auf github.com getan. Wenn du eine Karte verschiebst, ändert sich das Projekt, ein Kommentar wird in deinem Namen veröffentlicht, und wenn du ein Issue löschst, wird es auf GitHub gelöscht. Dafür gelten die Nutzungsbedingungen von GitHub, und du bist für das verantwortlich, was du in Projekten änderst, auf die du Zugriff hast.

Um die App mit deinen eigenen Projekten zu nutzen, brauchst du einen GitHub-Account. „Mit Beispieldaten ausprobieren“ funktioniert auch ohne.

Nicht mit GitHub verbunden

Issues ist eine unabhängige App. Sie wird von GitHub, Inc. weder entwickelt noch befürwortet oder gesponsert. GitHub und das GitHub-Logo sind Marken der GitHub, Inc.

Open Source

Der Quellcode ist unter der MIT-Lizenz öffentlich. Wenn du die App selbst aus dem Quellcode baust, gilt diese Lizenz anstelle der Standard-EULA.

Verfügbarkeit

Die App hängt von GitHub und dessen Schnittstelle für Apps ab. Wenn GitHub diese ändert oder einschränkt, können Teile der App nicht mehr funktionieren, bis ein Update erscheint. Die App wird kostenlos angeboten, ohne Zusage bestimmter Funktionen oder ständiger Verfügbarkeit.

Fragen

Schreib an issues.app@icloud.com. Wer hinter der App steckt, findest du im Impressum.
