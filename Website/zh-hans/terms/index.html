使用条款

Issues 是免费的。本条款适用于此 App 和本网站；条款之所以简短，是因为此 App 所做的不过是显示和更改你在 GitHub 上已有的内容。

最后更新：2026年10月5日

许可

从 App Store 获取的 Issues 依据 Apple 的许可应用程序最终用户许可协议（即“标准 EULA”）许可给你使用。以下各条是对其的补充，而非取代；如有不一致之处，以标准 EULA 为准。

你的 GitHub 账户

你使用自己的 GitHub 账户登录，此 App 代表你执行操作：你在其中所做的一切都会以你的名义在 GitHub 上发生，就像你在 github.com 上操作一样。移动卡片会更改项目，评论会以你的身份发布，删除议题会在 GitHub 上将其删除。这些操作适用 GitHub 的服务条款，你须对你在有权访问的项目中所做的更改负责。

要在此 App 中使用你自己的项目，你需要一个 GitHub 账户。“使用示例数据体验”无需账户即可使用。

与 GitHub 无关联

Issues 是一款独立的 App，并非由 GitHub, Inc. 制作、认可或赞助。GitHub 和 GitHub 徽标是 GitHub, Inc. 的商标。

开源

源代码依据 MIT 许可证公开。如果你自行从源代码构建此 App，则适用该许可证，而非标准 EULA。

可用性

此 App 依赖于 GitHub 及其面向 App 的接口。当 GitHub 更改或限制该接口时，此 App 的部分功能可能会停止工作，直到更新发布为止。此 App 免费提供，不承诺提供特定功能，也不承诺随时可用。

疑问

请写信至 issues.app@icloud.com。有关此 App 的提供者，请参阅 Impressum。
