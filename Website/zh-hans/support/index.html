常见问题

我需要 GitHub 账户吗？

要处理你自己的议题，需要。如果想先四处看看，可以在第一个屏幕上轻点使用示例数据体验：两个存储在你设备上的示例项目，所有功能都可以使用。

如何登录？

通过使用 GitHub 登录，或者使用具有 repo、project 和 read:org 作用域的经典（classic）个人访问令牌。在你的一台设备上登录后，其他设备会通过 iCloud 钥匙串自动登录。

为什么看不到我的议题？

看板显示的是 GitHub Project 中的议题，并以项目的“Status”字段作为列。你的项目所用的仓库也会显示在边栏中，并包含其中的所有议题：不在你的任何看板上的议题会列在无项目下，点按一下即可将其放到看板上。“我的议题”会显示分配给你的所有未关闭议题，无论它是否在看板上。

某个组织的项目不见了。

有些组织只允许使用其所有者批准过的 App。请让所有者批准 Issues，或者使用有权访问该组织的个人访问令牌登录。

可以离线使用吗？

可以。每项更改都会立即显示，并在设备上等待，直到有网络连接时再发送到 GitHub。如果在此期间有其他人更改了同一段文字，双方的编辑会被合并；对于重叠的部分，由你选择保留哪一个。

收件箱中会显示什么？

你在 GitHub 上收到的有关议题和拉取请求的通知：当有人将议题分配给你、提及你或你的团队、评论你关注的议题、请求你审查，或者关闭、重新打开或合并议题或拉取请求时。发行版、CI 运行和讨论会保留在 GitHub 上。你在收件箱中阅读或归档的通知，在 github.com 上也会显示为已读或已完成。GitHub 不会因卡片被移动或表情回应发送通知，因此收件箱也不会显示这些内容。你的到期议题也会显示在这里：在截止当天显示，如果次日早上仍未关闭，会再显示一次。你自己的账户在 App 之外分配给你的议题也会显示在这里，例如通过 gh、脚本或以你的账户登录的编程智能体：GitHub 不会就你自己账户的操作通知你，因此 App 会自行查找。你在 App 中将议题分配给自己时，不会显示在这里。

收件箱提示我的令牌无法读取通知。

GitHub 不允许细粒度（fine-grained）令牌读取通知。请使用 GitHub 登录，或者使用具有 repo 作用域的经典（classic）个人访问令牌；无论哪种方式，其他功能都能正常使用。

它会发送哪些通知？

到期议题的提醒：在分配给你的议题截止当天提醒一次，如果次日早上仍未关闭，会再提醒一次。你的每台设备都会根据截止日期自行安排这些提醒，因此能准时送达；你可以在“设置”中设定时间或关闭提醒。来自 GitHub 的其他消息，例如评论和提及，会在你打开 App 时显示在收件箱中，但不会以通知的形式推送：GitHub 只能通过 App 自己的服务器向 App 推送这些消息，而 Issues 刻意不设服务器。

截止日期可以包含具体时间吗？

不可以。截止日期是 GitHub 上项目的“Due date”字段，而 GitHub 的日期只精确到天，不含时间。提醒会在“设置”中设定的时间送达，默认是 9:00。

它支持哪些语言？

英语、德语、法语、西班牙语、葡萄牙语（巴西）、俄语、日语、韩语和简体中文。它会跟随你设备的语言。如果只想让 Issues 使用另一种语言，可以在 iPhone 和 iPad 上前往“设置 › App › Issues › 语言”进行选择，在 Mac 上则前往“系统设置 › 通用 › 语言与地区 › 应用程序”。来自 GitHub 的内容，例如标题、列和标签，会保持你的团队所写的原样。

如何删除我的数据？

退出登录会从设备上移除你的项目、议题和通知的副本；在所有设备上退出登录还会从 iCloud 钥匙串中移除登录信息。删除 App 会移除它存储的所有内容。详见隐私政策。

需要付费吗？

不需要。Issues 免费且开源；代码托管在 GitHub 上。
