サポート

質問、問題、アイデアはありますか？メールを送るか、GitHubでIssueを作成してください。すべてのメッセージに目を通しています。

メール issues.app@icloud.com GitHub Issues バグ報告や機能のリクエストを、公開の場で。 セキュリティ 脆弱性を非公開で報告できます。

よくある質問

GitHubアカウントは必要ですか？

自分のIssueを扱うには必要です。まず試してみたい場合は、最初の画面でサンプルデータで試すをタップしてください。デバイスに保存される2つのサンプルプロジェクトで、すべての機能を使えます。

サインインするには？

GitHubでサインインを使うか、repo、project、read:orgのスコープを持つ個人用アクセストークン（classic）を使います。いずれかのデバイスでサインインすれば、ほかのデバイスはiCloudキーチェーンを通じて自動的にサインインします。

Issueが表示されないのはなぜですか？

ボードには、GitHubプロジェクトに含まれるIssueが、プロジェクトの「Status」フィールドを列として表示されます。プロジェクトが使っているリポジトリもすべてのIssueとともにサイドバーにあり、どのボードにもないIssueはプロジェクトなしの下に表示されます。クリックひとつでボードに追加できます。「自分のIssue」には、ボードにあるかどうかに関係なく、あなたに割り当てられたオープンなIssueがすべて表示されます。

組織のプロジェクトが表示されません。

組織によっては、オーナーが承認したAppしか使えない場合があります。オーナーにIssuesを承認してもらうか、その組織にアクセスできる個人用アクセストークンでサインインしてください。

オフラインでも使えますか？

はい。変更はすぐに反映され、接続できるまでデバイスで待機してから、GitHubに送信されます。その間にほかの人が同じテキストを変更していた場合は編集内容が統合され、重なる部分はどちらを残すかを選択できます。

受信トレイには何が表示されますか？

IssueとプルリクエストについてのGitHubの通知です。担当者に割り当てられたとき、あなたやあなたのチームがメンションされたとき、フォロー中のIssueにコメントが付いたとき、レビューを依頼されたとき、そしてIssueやプルリクエストがクローズ、再オープン、マージされたときに表示されます。リリース、CIの実行、ディスカッションはGitHubに残ります。受信トレイで既読にしたものやアーカイブしたものは、github.comでも既読または完了になります。GitHubはカードの移動やリアクションを通知しないため、受信トレイにも表示されません。期日を迎えたあなたのIssueもここに表示されます。期日当日と、まだオープンなら翌朝にもう一度表示されます。

受信トレイに「このトークンでは通知を読み取れません」と表示されます。

GitHubでは、fine-grainedトークンで通知を読み取ることはできません。GitHubでサインインするか、repoスコープを持つ個人用アクセストークン（classic）を使用してください。それ以外の機能はどちらでも使えます。

どんな通知が届きますか？

期日を迎えたIssueのリマインダーです。あなたに割り当てられたIssueの期日当日と、まだオープンなら翌朝にもう一度届きます。各デバイスが期日をもとに自分でスケジュールするので、時間どおりに届きます。時刻の変更やオフへの切り替えは「設定」で行えます。コメントやメンションなど、GitHubからのその他のお知らせは、Appを開くたびに受信トレイに表示されますが、通知としては届きません。GitHubがそれらをAppにプッシュするにはApp独自のサーバが必要で、Issuesはあえてサーバを持っていないためです。

期日に時刻を設定できますか？

いいえ。期日はGitHub上のプロジェクトの「Due date」フィールドで、GitHubの日付は時刻を持たない日単位です。リマインダーは「設定」で指定した時刻に届きます（初期設定は9:00）。

どの言語に対応していますか？

英語、ドイツ語、フランス語、スペイン語、ポルトガル語（ブラジル）、ロシア語、日本語、韓国語、中国語（簡体字）です。デバイスの言語に従います。Issuesだけをほかの言語で使うには、iPhoneとiPadでは「設定」›「アプリ」›「Issues」›「言語」、Macでは「システム設定」›「一般」›「言語と地域」›「アプリケーション」で選択してください。タイトル、列、ラベルなど、GitHubから来るものはチームが書いたまま表示されます。

データを削除するには？

サインアウトすると、プロジェクト、Issue、通知のコピーがデバイスから削除されます。すべてのデバイスでサインアウトすると、iCloudキーチェーンからログイン情報も削除されます。Appを削除すると、Appが保存したものはすべて削除されます。詳しくはプライバシーポリシーをご覧ください。

料金はかかりますか？

いいえ。Issuesは無料のオープンソースで、コードはGitHubで公開されています。
