Condiciones de uso

Issues es gratis. Estas condiciones cubren la app y este sitio web; son breves porque la app hace poco más que mostrar y cambiar lo que ya tienes en GitHub.

Última actualización: 5 de octubre de 2026

La licencia

Issues del App Store se te concede bajo licencia conforme al Contrato de licencia de usuario final de la aplicación bajo licencia de Apple (el EULA estándar). Los puntos siguientes lo complementan y no lo sustituyen; cuando difieran, se aplica el EULA estándar.

Tu cuenta de GitHub

Inicias sesión con tu propia cuenta de GitHub, y la app actúa en tu nombre: lo que haces en ella ocurre en GitHub con tu nombre, como si lo hubieras hecho en github.com. Mover una tarjeta cambia el proyecto, un comentario se publica como tuyo y eliminar una incidencia la elimina en GitHub. A ello se aplican las Condiciones del servicio de GitHub, y eres responsable de lo que cambies en los proyectos a los que tienes acceso.

Para usar la app con tus propios proyectos necesitas una cuenta de GitHub. “Explorar con datos de ejemplo” funciona sin ella.

Sin afiliación con GitHub

Issues es una app independiente. No está hecha, respaldada ni patrocinada por GitHub, Inc. GitHub y el logotipo de GitHub son marcas comerciales de GitHub, Inc.

Código abierto

El código fuente es público bajo la licencia MIT. Si compilas tú mismo la app a partir del código fuente, se aplica esa licencia en lugar del EULA estándar.

Disponibilidad

La app depende de GitHub y de su interfaz para apps. Cuando GitHub la cambia o la limita, partes de la app pueden dejar de funcionar hasta que salga una actualización. La app se ofrece de forma gratuita, sin compromiso de ofrecer funciones concretas ni de estar disponible en todo momento.
