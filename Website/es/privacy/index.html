La app

Qué guarda y dónde

  • Tu inicio de sesión de GitHub (un token de acceso) se guarda en el llavero de tu dispositivo. Si usas la app en más de uno de tus dispositivos, se guarda en el Llavero de iCloud para que todos mantengan la sesión iniciada; Apple lo cifra de extremo a extremo.
  • Una copia de tus proyectos e incidencias, y de tus notificaciones de GitHub sobre incidencias y pull requests (Entrada), se guarda en una base de datos en tu dispositivo, para que la app se abra al instante y funcione sin conexión.
  • Los elementos de Entrada que pospusiste o marcaste como no leídos, y si leíste o archivaste una incidencia que vencía, se guardan en el almacenamiento clave-valor de iCloud de tu cuenta de Apple, para que tus dispositivos coincidan; GitHub no tiene dónde guardarlos. Contienen el número de la notificación en GitHub (o el id de la incidencia y el día en que vencía) y fechas, nada más, y se eliminan pasados 30 días. Nadie salvo tú y tus dispositivos puede leerlos.
  • Las preferencias, como el aspecto, el icono de la app, el orden de las secciones de las listas y la hora de los recordatorios, se quedan en tu dispositivo.
  • Los recordatorios de incidencias que vencen son notificaciones que tu dispositivo programa por sí mismo a partir de las fechas de vencimiento que ha sincronizado. No se envían a ninguna parte, y al desactivarlos en Ajustes se eliminan.

Qué envía y a quién

  • La app solo se comunica con GitHub: con api.github.com para leer y cambiar tus proyectos, incidencias y notificaciones, con github.com mientras inicias sesión, y con los servidores de imágenes de GitHub para los avatares y las imágenes de las descripciones de las incidencias. GitHub es el servicio en el que inicias sesión; lo que hace con tus datos se describe en la declaración de privacidad de GitHub.
  • Los elementos de Entrada pospuestos y no leídos van a tu cuenta de iCloud, a través de Apple, como se describe arriba.
  • Tu inicio de sesión no se envía a nadie más que a GitHub.
  • No se envía nada al desarrollador ni a ningún tercero. La app no contiene código de análisis, de publicidad ni de informes de fallos.
  • Si activaste Compartir con desarrolladores de apps en los ajustes de tu dispositivo, Apple transmite informes de fallos anónimos. Es una función de Apple y está en tus manos, en Ajustes › Privacidad y seguridad › Análisis y mejoras.

Datos de ejemplo

“Explorar con datos de ejemplo” muestra proyectos inventados guardados solo en tu dispositivo. Nada de lo que hagas ahí se envía a ninguna parte.

Eliminar tus datos

Cerrar sesión elimina del dispositivo la copia de tus proyectos, incidencias y notificaciones. Cerrar sesión en todas partes también elimina tu inicio de sesión del Llavero de iCloud, lo que cierra la sesión en todos tus dispositivos. Al eliminar la app se borra todo lo que guardó. Tus proyectos e incidencias en sí están en GitHub y se quedan allí.

Este sitio web

Este sitio web está alojado en GitHub Pages, un servicio de GitHub, Inc., 88 Colin P. Kelly Jr. St., San Francisco, CA 94107, USA. Para entregar una página, GitHub recibe tu dirección IP y los datos habituales de la solicitud (qué página, cuándo, qué navegador). GitHub registra las direcciones IP de los visitantes por motivos de seguridad. Esto se basa en el interés legítimo en ofrecer el sitio web de forma fiable y segura (art. 6, apdo. 1, letra f, del RGPD). GitHub ha certificado que cumple el Marco de Privacidad de Datos UE-EE. UU.; consulta la declaración de privacidad de GitHub.

Este sitio web no instala cookies ni usa análisis ni seguimiento. Sus tipos de letra, imágenes y estilos vienen con la página; no se carga nada de otros servidores. Los enlaces a GitHub y al App Store llevan a esos servicios, donde se aplican sus propias políticas de privacidad.

Cuando escribes

Si envías un correo, tu dirección y tu mensaje solo se usan para responderte (art. 6, apdo. 1, letras b y f, del RGPD) y se eliminan cuando termina la conversación, salvo que la ley obligue a conservarlos más tiempo.

Tus derechos

Según el RGPD, puedes preguntar qué datos sobre ti se tratan, pedir que se rectifiquen o se supriman, limitar su tratamiento, recibirlos en un formato portable y oponerte al tratamiento basado en el interés legítimo. Escribe a la dirección indicada arriba. También puedes presentar una reclamación ante una autoridad de protección de datos, por ejemplo el Comisionado de Berlín para la Protección de Datos y la Libertad de Información.

Cambios

Cuando la app o este sitio web cambien la forma en que tratan los datos, esta página cambiará con ellos. La fecha de arriba indica cuándo cambió por última vez.

Esto es una traducción. Si difiere de la versión en inglés, se aplica la versión en inglés.
