앱

저장하는 정보와 저장 위치

  • GitHub 로그인 정보(액세스 토큰)는 기기의 키체인에 보관됩니다. 여러 기기에서 앱을 사용하는 경우 모든 기기가 로그인 상태를 유지하도록 iCloud 키체인에 저장되며, Apple이 이를 종단 간 암호화합니다.
  • 프로젝트와 이슈의 사본, 그리고 이슈와 풀 리퀘스트에 관한 GitHub 알림(수신함)의 사본은 기기의 데이터베이스에 보관됩니다. 그래서 앱이 즉시 열리고 오프라인에서도 작동합니다.
  • 다시 알림을 설정했거나 읽지 않음으로 표시한 수신함 항목, 앱이 직접 만드는 항목(마감일이 된 이슈, 또는 앱 밖에서 내 계정으로 나에게 할당된 이슈)을 읽었거나 보관했는지 여부, 그리고 앱에서 나에게 이슈를 할당한 시각은 기기 간에 일치하도록 Apple 계정의 iCloud 키-값 저장소에 보관됩니다. GitHub에는 이를 저장할 곳이 없기 때문입니다. 여기에는 GitHub에서의 알림 번호(또는 이슈의 ID, 마감일, GitHub에서의 할당 ID)와 날짜만 담기며, 30일 후에 삭제되고, 앱에서 한 할당의 기록은 1주일 후에 삭제됩니다. 본인과 본인의 기기만 이를 읽을 수 있습니다.
  • 화면 모드, 앱 아이콘, 목록 섹션의 순서, 미리 알림 시간 같은 환경설정은 기기에만 남습니다.
  • 마감일이 된 이슈의 미리 알림은 기기가 동기화한 마감일을 바탕으로 직접 예약하는 알림입니다. 어디로도 전송되지 않으며, 설정에서 끄면 제거됩니다.

전송하는 정보와 전송 대상

  • 앱은 GitHub와만 통신합니다. 프로젝트, 이슈, 알림을 읽고 변경할 때는 api.github.com, 로그인하는 동안에는 github.com, 아바타와 이슈 설명 속 이미지에는 GitHub의 이미지 서버를 사용합니다. GitHub는 사용자가 로그인하는 서비스이며, GitHub가 사용자의 데이터로 하는 일은 GitHub의 개인정보 처리방침에 설명되어 있습니다.
  • 다시 알림을 설정했거나 읽지 않음으로 표시한 수신함 항목은 위에서 설명한 대로 Apple을 통해 사용자의 iCloud 계정으로 전송됩니다.
  • 로그인 정보는 GitHub 외에는 누구에게도 전송되지 않습니다.
  • 개발자나 다른 어떤 당사자에게도 아무것도 전송되지 않습니다. 앱에는 분석, 광고, 충돌 보고 코드가 없습니다.
  • 기기 설정에서 앱 개발자와 공유를 켠 경우 Apple이 익명 충돌 보고서를 전달합니다. 이는 Apple의 기능이며 설정 › 개인정보 보호 및 보안 › 분석 및 향상에서 직접 관리할 수 있습니다.

샘플 데이터

“샘플 데이터로 둘러보기”는 기기에만 저장된 가상의 프로젝트를 보여 줍니다. 그곳에서 하는 어떤 작업도 어디로도 전송되지 않습니다.

데이터 삭제

로그아웃하면 기기에서 프로젝트, 이슈, 알림의 사본이 제거됩니다. 모든 기기에서 로그아웃하면 iCloud 키체인에서 로그인 정보도 제거되어 모든 기기에서 로그아웃됩니다. 앱을 삭제하면 앱이 저장한 모든 항목이 제거됩니다. 프로젝트와 이슈 자체는 GitHub에 있으며 그대로 유지됩니다.

이 웹사이트

이 웹사이트는 GitHub, Inc.(88 Colin P. Kelly Jr. St., San Francisco, CA 94107, USA)의 서비스인 GitHub Pages에서 호스팅됩니다. 페이지를 전달하기 위해 GitHub는 사용자의 IP 주소와 요청의 일반적인 세부 정보(어떤 페이지를, 언제, 어떤 브라우저로)를 받습니다. GitHub는 보안 목적으로 방문자의 IP 주소를 기록합니다. 이는 웹사이트를 안정적이고 안전하게 제공하려는 정당한 이익(GDPR 제6조 제1항 (f))에 근거합니다. GitHub는 EU-미국 데이터 프라이버시 프레임워크(EU-U.S. Data Privacy Framework)를 준수한다고 인증했습니다. GitHub의 개인정보 처리방침을 참고하세요.

이 웹사이트는 쿠키를 설정하지 않으며 분석이나 추적을 사용하지 않습니다. 글꼴, 이미지, 스타일은 페이지와 함께 제공되며 다른 서버에서 아무것도 불러오지 않습니다. GitHub와 App Store로 연결되는 링크는 해당 서비스로 이동하며, 그곳에서는 각 서비스의 개인정보 처리방침이 적용됩니다.

이메일을 보내는 경우

이메일을 보내면 이메일 주소와 메시지는 답장하는 데에만 사용되며(GDPR 제6조 제1항 (b) 및 (f)), 법률상 더 오래 보관해야 하는 경우가 아니면 대화가 끝난 후 삭제됩니다.

사용자의 권리

GDPR에 따라 사용자는 자신에 관해 어떤 데이터가 처리되는지 문의하고, 데이터의 정정 또는 삭제를 요청하고, 처리를 제한하고, 데이터를 이동 가능한 형식으로 받고, 정당한 이익에 근거한 처리에 반대할 수 있습니다. 위 주소로 연락하세요. 또한 데이터 보호 감독 기관에 불만을 제기할 수 있습니다. 예를 들어 베를린 데이터 보호 및 정보 자유 감독관이 있습니다.

변경 사항

앱 또는 이 웹사이트의 데이터 처리 방식이 바뀌면 이 페이지도 함께 변경됩니다. 맨 위의 날짜는 마지막으로 변경된 날을 나타냅니다.
