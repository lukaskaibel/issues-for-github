질문이나 문제, 아이디어가 있나요? 이메일을 보내거나 GitHub에 이슈를 남겨 주세요. 모든 메시지를 읽습니다.

이메일 issues.app@icloud.com GitHub Issues 버그 신고와 기능 요청을 공개적으로 남깁니다. 보안 취약점을 비공개로 제보합니다.

자주 묻는 질문

GitHub 계정이 필요한가요?

내 이슈로 작업하려면 필요합니다. 먼저 둘러보려면 첫 화면에서 샘플 데이터로 둘러보기를 탭하세요. 기기에 저장되는 샘플 프로젝트 2개에서 모든 기능을 사용할 수 있습니다.

어떻게 로그인하나요?

GitHub로 로그인을 사용하거나, repo, project, read:org 범위가 있는 개인용 액세스 토큰(클래식)으로 로그인합니다. 기기 하나에서 로그인하면 다른 기기는 iCloud 키체인을 통해 자동으로 로그인됩니다.

이슈가 보이지 않는 이유는 무엇인가요?

보드에는 GitHub 프로젝트에 있는 이슈가 표시되며, 프로젝트의 Status 필드가 보드의 열이 됩니다. 프로젝트에서 사용하는 저장소도 모든 이슈와 함께 사이드바에 표시됩니다. 어떤 보드에도 없는 이슈는 프로젝트 없음 아래에 나열되며, 클릭 한 번으로 보드에 추가할 수 있습니다. 내 이슈에는 나에게 할당된 열린 이슈가 보드에 있든 없든 모두 표시됩니다.

조직의 프로젝트가 보이지 않습니다.

일부 조직에서는 소유자가 승인한 앱만 허용합니다. 소유자에게 Issues를 승인해 달라고 요청하거나, 해당 조직에 접근할 수 있는 개인용 액세스 토큰으로 로그인하세요.

오프라인에서도 작동하나요?

예. 모든 변경 사항은 즉시 표시되고, 연결될 때까지 기기에서 대기한 다음 GitHub로 전송됩니다. 그사이 다른 사람이 같은 텍스트를 변경했다면 편집 내용이 병합되며, 겹치는 부분은 어느 쪽을 유지할지 직접 선택합니다.

수신함에는 무엇이 표시되나요?

이슈와 풀 리퀘스트에 관한 GitHub 알림이 표시됩니다. 누군가 나에게 할당하거나, 나 또는 내 팀을 멘션하거나, 내가 구독 중인 이슈에 댓글을 달거나, 리뷰를 요청하거나, 이슈를 닫거나 다시 열거나 병합한 경우입니다. 릴리스, CI 실행, 토론 알림은 GitHub에 남습니다. 수신함에서 읽거나 보관한 항목은 github.com에서도 읽음 또는 완료로 처리됩니다. GitHub는 카드 이동이나 반응을 알리지 않으므로 수신함에도 표시되지 않습니다. 마감일이 된 내 이슈도 수신함에 표시되며, 마감일 당일에 한 번, 아직 열려 있으면 다음 날 아침에 한 번 더 표시됩니다.

수신함에 토큰으로 알림을 읽을 수 없다고 표시됩니다.

GitHub에서는 세분화된 토큰으로 알림을 읽을 수 없습니다. GitHub로 로그인하거나 repo 범위가 있는 개인용 액세스 토큰(클래식)을 사용하세요. 다른 기능은 어느 쪽이든 모두 작동합니다.

어떤 알림을 보내나요?

마감일이 된 이슈의 미리 알림을 보냅니다. 나에게 할당된 이슈의 마감일 당일에 알리고, 아직 열려 있으면 다음 날 아침에 한 번 더 알립니다. 각 기기가 마감일을 바탕으로 직접 일정을 잡으므로 제시간에 도착합니다. 시간을 지정하거나 알림을 끄려면 설정을 이용하세요. 댓글이나 멘션 같은 GitHub의 다른 소식은 앱을 열 때마다 수신함에 표시되지만 알림으로 오지는 않습니다. GitHub가 이런 소식을 앱에 푸시하려면 앱 자체 서버가 필요한데, Issues는 의도적으로 서버를 두지 않기 때문입니다.

마감일에 시간을 지정할 수 있나요?

아니요. 마감일은 GitHub에 있는 프로젝트의 “Due date” 필드이며, GitHub의 날짜에는 시간 없이 날짜만 있습니다. 미리 알림은 설정에서 지정한 시간에 오며, 처음에는 오전 9:00으로 설정되어 있습니다.

어떤 언어를 지원하나요?

영어, 독일어, 프랑스어, 스페인어, 포르투갈어(브라질), 러시아어, 일본어, 한국어, 중국어(간체)를 지원하며, 기기의 언어를 따릅니다. Issues에서만 다른 언어를 사용하려면 iPhone 및 iPad에서는 설정 › 앱 › Issues › 언어에서, Mac에서는 시스템 설정 › 일반 › 언어 및 지역 › 응용 프로그램에서 선택하세요. 제목, 열, 레이블처럼 GitHub에서 가져온 내용은 팀이 작성한 그대로 표시됩니다.

내 데이터를 삭제하려면 어떻게 하나요?

로그아웃하면 기기에서 프로젝트, 이슈, 알림의 사본이 제거됩니다. 모든 기기에서 로그아웃하면 iCloud 키체인에서 로그인 정보도 제거됩니다. 앱을 삭제하면 앱이 저장한 모든 항목이 제거됩니다. 자세한 내용은 개인정보 처리방침을 참고하세요.

비용이 드나요?

아니요. Issues는 무료 오픈 소스 앱이며, 코드는 GitHub에 있습니다.
