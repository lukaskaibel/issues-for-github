Issues GitHub

이용 약관

Issues는 무료입니다. 이 약관은 앱과 이 웹사이트에 적용됩니다. 앱은 이미 GitHub에 있는 내용을 보여 주고 변경하는 것 외에는 거의 하는 일이 없으므로 약관도 짧습니다.

최종 업데이트: 2026년 10월 5일

라이선스

App Store에서 받은 Issues는 Apple의 라이선스 애플리케이션 최종 사용자 사용권 계약(Licensed Application End User License Agreement)(표준 EULA)에 따라 사용자에게 사용권이 부여됩니다. 아래 사항은 이 계약에 추가되는 것이며 이를 대체하지 않습니다. 서로 다른 경우에는 표준 EULA가 적용됩니다.

GitHub 계정

사용자는 자신의 GitHub 계정으로 로그인하며, 앱은 사용자를 대신하여 작동합니다. 앱에서 하는 작업은 github.com에서 한 것과 마찬가지로 사용자의 이름으로 GitHub에서 이루어집니다. 카드를 이동하면 프로젝트가 변경되고, 댓글은 사용자의 이름으로 게시되며, 이슈를 삭제하면 GitHub에서 삭제됩니다. 여기에는 GitHub의 서비스 약관이 적용되며, 사용자는 접근 권한이 있는 프로젝트에서 변경한 내용에 대해 책임을 집니다.

자신의 프로젝트로 앱을 사용하려면 GitHub 계정이 필요합니다. “샘플 데이터로 둘러보기”는 계정 없이도 작동합니다.

GitHub와 제휴 관계 없음

Issues는 독립적인 앱입니다. GitHub, Inc.가 만들거나 보증하거나 후원하는 앱이 아닙니다. GitHub 및 GitHub 로고는 GitHub, Inc.의 상표입니다.

오픈 소스

소스 코드는 MIT 라이선스에 따라 공개되어 있습니다. 소스에서 앱을 직접 빌드하는 경우에는 표준 EULA 대신 해당 라이선스가 적용됩니다.

이용 가능성

앱은 GitHub와 앱을 위한 GitHub의 인터페이스에 의존합니다. GitHub가 이를 변경하거나 제한하면 업데이트가 나올 때까지 앱의 일부 기능이 작동하지 않을 수 있습니다. 앱은 무료로 제공되며, 특정 기능이나 항상 이용할 수 있음을 약속하지 않습니다.
