L’app

Ce qu’elle enregistre, et où

  • Vos identifiants GitHub (un jeton d’accès) sont conservés dans le trousseau de votre appareil. Si vous utilisez l’app sur plusieurs de vos appareils, ils sont enregistrés dans le trousseau iCloud afin que tous restent connectés ; Apple les chiffre de bout en bout.
  • Une copie de vos projets et tickets, ainsi que de vos notifications GitHub concernant les tickets et les pull requests (Réception), est conservée dans une base de données sur votre appareil, afin que l’app s’ouvre instantanément et fonctionne hors ligne.
  • Les éléments de Réception que vous avez mis en attente ou marqués comme non lus, le fait d’avoir lu ou archivé un élément que l’app crée elle-même (un ticket arrivé à échéance, ou un ticket que votre propre compte vous a assigné en dehors de l’app), ainsi que le moment où vous vous êtes assigné un ticket dans l’app, sont conservés dans le stockage clé-valeur iCloud de votre compte Apple, afin que vos appareils restent synchronisés ; GitHub n’a pas d’emplacement pour cela. Ils contiennent le numéro de la notification sur GitHub (ou l’identifiant du ticket, le jour de son échéance ou l’identifiant de l’assignation sur GitHub) et des dates, rien d’autre, et sont supprimés au bout de 30 jours, les assignations faites dans l’app au bout d’une semaine. Seuls vous et vos appareils pouvez les lire.
  • Les préférences, comme l’apparence, l’icône de l’app, l’ordre des sections des listes et l’heure des rappels, restent sur votre appareil.
  • Les rappels des tickets arrivés à échéance sont des notifications que votre appareil planifie lui-même à partir des échéances qu’il a synchronisées. Ils ne sont envoyés nulle part, et les désactiver dans les réglages les supprime.

Ce qu’elle envoie, et à qui

  • L’app communique uniquement avec GitHub : api.github.com pour lire et modifier vos projets, tickets et notifications, github.com pendant la connexion, et les serveurs d’images de GitHub pour les avatars et les images des descriptions de tickets. GitHub est le service auquel vous vous connectez ; ce qu’il fait de vos données est décrit dans la déclaration de confidentialité de GitHub.
  • Les éléments de Réception mis en attente et non lus sont envoyés à votre compte iCloud, via Apple, comme décrit ci-dessus.
  • Vos identifiants ne sont envoyés à personne d’autre que GitHub.
  • Rien n’est envoyé au développeur ni à quiconque d’autre. L’app ne contient aucun code d’analyse, de publicité ou de rapport de plantage.
  • Si vous avez activé Partager avec les développeurs d’apps dans les réglages de votre appareil, Apple transmet des rapports de plantage anonymes. Il s’agit d’une fonctionnalité d’Apple, que vous contrôlez dans Réglages › Confidentialité et sécurité › Analyse et améliorations.

Données d’exemple

« Explorer avec des données d’exemple » affiche des projets fictifs enregistrés uniquement sur votre appareil. Rien de ce que vous y faites n’est envoyé nulle part.

Supprimer vos données

Se déconnecter supprime de l’appareil la copie de vos projets, tickets et notifications. Se déconnecter partout supprime aussi vos identifiants du trousseau iCloud, ce qui déconnecte tous vos appareils. Supprimer l’app efface tout ce qu’elle a enregistré. Vos projets et tickets eux-mêmes se trouvent sur GitHub et y restent.

Ce site

Ce site est hébergé par GitHub Pages, un service de GitHub, Inc., 88 Colin P. Kelly Jr. St., San Francisco, CA 94107, États-Unis. Pour transmettre une page, GitHub reçoit votre adresse IP et les informations habituelles de la requête (quelle page, quand, quel navigateur). GitHub enregistre les adresses IP des visiteurs à des fins de sécurité. Ce traitement repose sur l’intérêt légitime à fournir le site de manière fiable et sûre (art. 6, paragraphe 1, point f, du RGPD). GitHub a certifié adhérer au cadre de protection des données UE–États-Unis (EU-U.S. Data Privacy Framework) ; voir la déclaration de confidentialité de GitHub.

Le site ne dépose aucun cookie et n’utilise aucun outil d’analyse ni de pistage. Ses polices, images et styles sont fournis avec la page ; rien n’est chargé depuis d’autres serveurs. Les liens vers GitHub et l’App Store mènent à ces services, où s’appliquent leurs propres politiques de confidentialité.

Quand vous écrivez

Si vous envoyez un e-mail, votre adresse et votre message ne servent qu’à vous répondre (art. 6, paragraphe 1, points b et f, du RGPD) et sont supprimés une fois l’échange terminé, sauf si la loi impose de les conserver plus longtemps.

Vos droits

En vertu du RGPD, vous pouvez demander quelles données vous concernant sont traitées, les faire rectifier ou effacer, en limiter le traitement, les recevoir dans un format portable et vous opposer à un traitement fondé sur l’intérêt légitime. Écrivez à l’adresse ci-dessus. Vous pouvez aussi introduire une réclamation auprès d’une autorité de protection des données, par exemple l’autorité berlinoise chargée de la protection des données et de la liberté d’information.

Modifications

Lorsque l’app ou ce site change sa façon de traiter les données, cette page change aussi. La date en haut indique sa dernière modification.
