Termos de Uso

O Issues é gratuito. Estes termos abrangem o app e este site; são curtos porque o app faz pouco além de mostrar e alterar o que você já tem no GitHub.

Última atualização: 5 de outubro de 2026

A licença

O Issues da App Store é licenciado a você nos termos do Licensed Application End User License Agreement da Apple (o Contrato de Licença de Usuário Final padrão, “Standard EULA”). Os pontos abaixo o complementam e não o substituem; onde houver divergência, prevalece o Standard EULA.

Sua conta do GitHub

Você inicia sessão com a sua própria conta do GitHub, e o app age em seu nome: o que você faz nele acontece no GitHub com o seu nome, como se você tivesse feito em github.com. Mover um cartão altera o projeto, um comentário é publicado em seu nome, e apagar uma issue a apaga no GitHub. Os Termos de Serviço do GitHub se aplicam a isso, e você é responsável pelo que alterar em projetos aos quais tem acesso.

Para usar o app com os seus próprios projetos, você precisa de uma conta do GitHub. “Explorar com dados de exemplo” funciona sem conta.

Sem afiliação com o GitHub

O Issues é um app independente. Ele não é feito, endossado nem patrocinado pela GitHub, Inc. GitHub e o logotipo do GitHub são marcas registradas da GitHub, Inc.

Código aberto

O código-fonte é público sob a licença MIT. Se você compilar o app por conta própria a partir do código-fonte, essa licença se aplica no lugar do Standard EULA.

Disponibilidade

O app depende do GitHub e da sua interface para apps. Quando o GitHub a altera ou limita, partes do app podem deixar de funcionar até que saia uma atualização. O app é oferecido gratuitamente, sem promessa de recursos específicos nem de estar disponível o tempo todo.

Dúvidas

Escreva para issues.app@icloud.com. Quem está por trás do app consta no Impressum.
