Issues는 Mac, iPhone, iPad에서 GitHub Issues와 GitHub Projects를 사용하는 빠른 네이티브 앱입니다. Mail과 메모 앱처럼 구성된 화면에 키보드 중심의 빠른 조작, 그리고 모든 내용은 GitHub에 그대로 남습니다. 이 앱을 사용하지 않는 팀원도 github.com에서 같은 이슈와 보드를 봅니다.

[미리 계획하기]
• 마일스톤: 보드의 다가오는 마일스톤이 사이드바에 표시되고, 각 마일스톤의 이슈, 진행률, 마감일을 볼 수 있습니다
• 에픽: 작업을 이루는 이슈를 하위 이슈로 묶는 이슈입니다. 보드에서는 에픽의 이슈가 에픽 이름 아래에 함께 모이며, 이름을 드래그하면 모든 이슈를 한꺼번에 옮길 수 있습니다
• 로드맵: 에픽이 마일스톤에 걸친 막대로 표시되며, 월별 또는 분기별로 볼 수 있습니다. 막대를 드래그하면 에픽과 그 이슈를 다른 마일스톤으로 옮길 수 있습니다
• “이번 주”나 열린 버그처럼 GitHub에 있는 프로젝트의 보기를 보드나 목록으로 열고, 필터는 클릭 한 번으로 바꿀 수 있습니다
• 마일스톤이나 상위 이슈로 그룹화한 보기는 그룹마다 진행률을, 현재 이터레이션의 보기는 남은 일수를 보여 주며, 로드맵 보기는 타임라인으로 표시됩니다

[수신함]
• GitHub 알림에서 나와 관련된 소식을 보여 줍니다. 누가 나에게 이슈를 할당했는지, 나를 멘션했는지, 댓글을 남겼는지, 리뷰를 요청했는지, 내가 구독 중인 이슈를 닫았는지 알 수 있습니다
• 알림을 열면 바로 이슈가 표시되며, 새로운 내용은 맨 위에 있습니다
• 키 하나나 스와이프로 읽음, 보관, 다시 알림을 처리하며, github.com과 모든 기기에 똑같이 반영됩니다

[Mac에서]
• 모든 프로젝트를 보드 또는 목록으로 보고, 내 이슈에서는 나에게 할당된 모든 항목을, 저장소에서는 어떤 보드에도 없는 이슈까지 모두 확인합니다
• 이슈를 드래그해 위치를 바꾸고, 열을 추가하고 이름, 색상, 순서를 변경합니다
• 키보드 중심: J와 K로 이슈 사이를 이동하고, S, P, A, L로 상태, 우선순위, 담당자, 레이블을 변경하며, D로 마감일을 설정하고, ⌘K로 그 밖의 모든 작업을 위한 명령 팔레트를 엽니다
• 여러 이슈를 선택해 한 번에 변경하거나, 스페이스 키로 이슈를 훑어봅니다
• 하위 이슈와 차단 관계: 어떤 이슈든 다른 이슈 아래에 두고, 어떤 이슈가 어떤 이슈를 차단하는지 표시합니다
• 설명은 GitHub에서처럼 표, 체크할 수 있는 체크리스트, Mermaid 다이어그램과 함께 표시됩니다

[iPhone과 iPad에서]
• iPhone에서는 수신함, 내 이슈, 프로젝트, 검색을 탭으로 오가고, iPad에서는 사이드바와 드래그 앤 드롭을 지원하는 보드를 사용합니다
• 오른쪽으로 스와이프하면 이슈를 완료로 표시하고, 왼쪽으로 스와이프하면 나에게 할당하거나 삭제합니다
• 이슈를 길게 터치하면 상태, 우선순위, 담당자, 레이블, 마일스톤, 상위 이슈, 차단 관계를 변경하거나 새 위치로 드래그할 수 있습니다
• 마일스톤과 로드맵을 사용할 수 있으며, iPad에서는 로드맵이 타임라인으로 표시됩니다
• iPad에 키보드를 연결하면 Mac과 같은 키보드 단축키를 사용할 수 있습니다

[알려 주는 마감일]
• 이슈에 마감일을 지정합니다. 내일, 금요일, 캘린더에서 고른 날짜, 또는 “3일 후”처럼 입력할 수 있습니다
• 당일에는 Mac, iPhone, iPad가 알려 주며, 이슈를 시작하거나 완료로 표시하거나 내일로 미루는 버튼이 함께 표시됩니다
• 날짜는 GitHub에 있는 프로젝트의 Due date 필드이므로 팀원도 볼 수 있습니다

[빠르고 안정적]
• 모든 변경 사항은 즉시 표시되고 백그라운드에서 GitHub로 전송됩니다
• 오프라인에서도 작동합니다. 변경 사항은 대기했다가 다시 온라인 상태가 되면 전송됩니다
• 다른 사람의 작업을 존중합니다. 다른 사람이 같은 텍스트를 변경했다면 아무것도 덮어쓰지 않습니다

[개인정보 보호]
• 계정도, 서버도, 추적도 없습니다. 로그인 정보는 키체인에 보관되며 GitHub로만 전송됩니다.
• 기기 하나에서 로그인했나요? 다른 기기는 iCloud 키체인을 통해 자동으로 로그인됩니다.

영어, 독일어, 프랑스어, 스페인어, 포르투갈어, 러시아어, 일본어, 한국어, 중국어를 지원하며, 기기의 언어를 따릅니다.

계정 없이 사용해 보세요. “샘플 데이터로 둘러보기”를 누르면 샘플 프로젝트 2개가 열립니다.
