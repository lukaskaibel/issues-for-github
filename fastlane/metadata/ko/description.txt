Issues는 Mac, iPhone, iPad에서 GitHub Issues와 GitHub Projects를 사용하는 빠른 네이티브 앱입니다. 차분한 화면에 빠른 조작, 그리고 모든 내용은 GitHub에 그대로 남습니다. 이 앱을 사용하지 않는 팀원도 github.com에서 같은 이슈와 보드를 봅니다.

[수신함]
• GitHub 알림에서 나와 관련된 소식을 보여 줍니다. 누가 나에게 이슈를 할당했는지, 나를 멘션했는지, 댓글을 남겼는지, 리뷰를 요청했는지, 내가 구독 중인 이슈를 닫았는지 알 수 있습니다
• 알림을 열면 바로 이슈가 표시되며, 새로운 내용은 맨 위에, 새 댓글에는 표시가 붙습니다
• 마감일이 된 내 이슈는 당일에 시작, 완료로 표시, 내일로 미루기 버튼과 함께 표시됩니다
• 키 하나나 스와이프로 읽음, 보관, 다시 알림을 처리하며, 읽음과 보관 상태는 github.com에도 똑같이 반영됩니다
• 다시 알림을 설정한 항목과 읽지 않은 항목은 iCloud를 통해 모든 기기에서 동기화됩니다

[Mac에서]
• 모든 프로젝트를 보드 또는 목록으로 보고, 내 이슈에서 나에게 할당된 모든 항목을 확인합니다
• 어떤 보드에도 없는 이슈까지 저장소의 모든 이슈를 보여 주며, 클릭 한 번으로 보드에 추가할 수 있습니다
• 보드나 목록에서 이슈를 드래그해 위치를 바꾸고, 열을 추가하고 이름, 색상, 순서를 변경합니다
• 키보드 중심: J와 K로 이슈 사이를 이동하고, S, P, A, L로 상태, 우선순위, 담당자, 레이블을 변경하며, D로 마감일을 설정하고, ⌘K로 그 밖의 모든 작업을 위한 명령 팔레트를 엽니다
• 여러 이슈를 선택해 한 번에 변경합니다
• 스페이스 키로 이슈를 훑어보거나, 속성, 하위 이슈, 댓글과 나란히 엽니다
• 하위 이슈와 차단 관계: 어떤 이슈든 다른 이슈 아래에 두고, 기존 이슈를 하위 이슈로 추가하고, 어떤 이슈가 어떤 이슈를 차단하는지 표시합니다
• 설명은 GitHub에서처럼 표, 체크할 수 있는 체크리스트, Mermaid 다이어그램과 함께 표시됩니다
• 뒤로 및 앞으로 이동은 브라우저처럼 작동합니다

[iPhone에서]
• 첫 번째 탭인 수신함에 읽지 않은 알림 수가 표시됩니다
• 내 이슈에서 나에게 할당된 모든 항목을 상태별로 묶어 보여 줍니다
• 모든 프로젝트와 저장소를 접을 수 있는 섹션이 있는 목록으로 봅니다
• 오른쪽으로 스와이프하면 이슈를 완료로 표시하고, 왼쪽으로 스와이프하면 나에게 할당하거나 삭제합니다
• 이슈를 길게 터치하면 상태, 우선순위, 담당자, 레이블, 상위 이슈, 차단 관계를 변경하거나 새 위치로 드래그할 수 있습니다
• 모든 프로젝트에서 제목이나 번호로 검색합니다
• 설명 속 표, 체크리스트, Mermaid 다이어그램이 GitHub에서처럼 표시됩니다

[iPad에서]
• 모든 프로젝트와 저장소가 있는 사이드바, 드래그 앤 드롭을 지원하는 보드
• Mail 앱처럼 이슈를 옆에 함께 보여 주는 수신함
• Mac에서처럼 이슈를 속성과 나란히 엽니다
• 키보드 사용 시: J와 K로 이동, S, P, A, L로 이슈 변경, ⌘N으로 새 이슈 생성

[알려 주는 마감일]
• 이슈에 마감일을 지정합니다. 내일, 금요일, 다음 주, 캘린더에서 고른 날짜, 또는 “3일 후”처럼 입력할 수 있습니다
• 카드와 목록에 마감일이 표시되며, 당일에는 주황색, 지나면 빨간색으로 바뀝니다
• 당일에는 Mac, iPhone, iPad가 알려 주며, 이슈를 시작하거나 완료로 표시하거나 내일로 미루는 버튼이 함께 표시됩니다
• 날짜는 GitHub에 있는 프로젝트의 Due date 필드이므로 팀원도 볼 수 있습니다

[빠르고 안정적]
• 모든 변경 사항은 즉시 표시되고 백그라운드에서 GitHub로 전송됩니다
• 오프라인에서도 작동합니다. 변경 사항은 대기했다가 다시 온라인 상태가 되면 전송됩니다
• 다른 사람의 작업을 존중합니다. 다른 사람이 같은 텍스트를 변경했다면 아무것도 덮어쓰지 않습니다

[개인정보 보호]
• 계정도, 서버도, 추적도 없습니다. 로그인 정보는 키체인에 보관되며 GitHub로만 전송됩니다.
• 기기 하나에서 로그인했나요? 다른 기기는 iCloud 키체인을 통해 자동으로 로그인됩니다.

영어, 독일어, 프랑스어, 스페인어, 포르투갈어, 러시아어, 일본어, 한국어, 중국어를 지원하며, 기기의 언어를 따릅니다.

계정 없이 사용해 보세요. “샘플 데이터로 둘러보기”를 누르면 샘플 프로젝트 2개가 열립니다.

Issues는 오픈 소스입니다: github.com/lukaskaibel/issues-for-github
Issues는 GitHub와 제휴 관계가 없으며 GitHub의 보증을 받지 않았습니다.
