Issues가 이제 9개 언어를 지원하고, 수신함이 추가되었으며, 마감일이 된 이슈를 알려 줍니다.

• 9개 언어: 영어, 독일어, 프랑스어, 스페인어, 포르투갈어, 러시아어, 일본어, 한국어, 중국어를 지원하며, 기기의 언어를 따릅니다
• 수신함: GitHub 알림을 해당 이슈와 나란히 보여 줍니다. 키나 스와이프로 읽음으로 표시하고, 보관하고, 다시 알림을 설정할 수 있으며, github.com과 다른 기기에도 똑같이 반영됩니다. 오늘 마감인 이슈와, gh나 코딩 에이전트 등으로 내 계정이 앱 밖에서 나에게 할당한 이슈도 여기에 표시됩니다
• 마감일과 알림: 날짜를 고르거나 “3일 후”처럼 입력하면, 그날 Mac, iPhone, iPad가 알려 줍니다
• 하위 이슈는 보드와 목록에서 상위 이슈 바로 아래에 표시되며, 화살표로 접을 수 있습니다. 마지막 하위 이슈를 완료하면 상위 이슈도 완료됩니다
• 하위 이슈와 차단 관계: 기존 이슈를 하위 이슈로 추가하고, 이슈에 상위 이슈를 지정하고, 어떤 이슈가 어떤 이슈를 차단하는지 표시합니다
• 보드에 있든 없든 모든 이슈: 사이드바에 저장소가 표시되고, 어떤 보드에도 없는 이슈는 “프로젝트 없음” 아래에 모입니다. 클릭 한 번으로 보드에 추가할 수 있습니다
• GitHub에서처럼 표시되는 설명: 표, 체크할 수 있는 체크리스트, 코드, Mermaid 다이어그램
• 보드뿐 아니라 목록에서도 이슈를 드래그해 새 위치로 옮길 수 있습니다
• 클릭 수 감소: 상태, 담당자, 레이블을 고르면 선택 창이 바로 닫힙니다. 여러 개를 고르려면 행 앞의 체크박스를 사용합니다
• iPad를 가로 방향으로 돌리면 앱이 종료될 수 있던 문제를 수정했습니다
