Issues 是一款快速的原生 App，让你在 Mac、iPhone 和 iPad 上使用 GitHub Issues 和 GitHub Projects。它的设计与“邮件”和“备忘录”一脉相承，用键盘即可快速操作，而且所有内容都保留在 GitHub 中：不使用此 App 的队友在 github.com 上看到的是同样的议题和看板。

【提前规划】
• 里程碑：边栏中显示看板接下来的几个里程碑，每个都列出其议题、完成进度和截止日期
• 史诗：由子议题组成的议题。在看板上，史诗的议题会集中在它的名称下；拖动名称即可将它们整体移动
• 路线图：你的史诗以横条形式显示在里程碑上，可按月或按季度查看。拖动横条，即可将史诗及其议题移到另一个里程碑
• 你的项目在 GitHub 上的视图，例如“本周”或未关闭的 Bug，可显示为看板或列表，筛选条件点按一下即可更改
• 按里程碑或父议题分组时，视图会显示每组的进度；当前迭代的视图会显示剩余天数；路线图视图则显示为时间线

【收件箱】
• 根据 GitHub 的通知，了解与你相关的变化：谁将议题分配给你、提及了你、发表了评论、请求你审查，或关闭了你关注的议题
• 打开一条通知，议题随即呈现，最新动态位于顶部
• 按一个键或轻扫一下即可标记已读、归档和稍后提醒；在 github.com 和你的所有设备上都会保持一致

【Mac 版】
• 每个项目都可以显示为看板或列表，“我的议题”汇集了分配给你的所有议题，还能查看你的仓库中的每个议题，包括不在任何看板上的议题
• 将议题拖到新位置，并调整列：添加、重新命名、更改颜色和重新排序
• 键盘优先：J 和 K 在议题间移动，S、P、A 和 L 分别更改状态、优先级、负责人和标签，D 设置截止日期，⌘K 打开命令面板，处理其他一切操作
• 选择多个议题，一次性更改，或按空格键快速查看某个议题
• 子议题和阻塞关系：将任意议题放到另一个议题之下，并标记哪个议题阻塞了哪个
• 描述的呈现方式与 GitHub 一致，支持表格、可勾选的清单和 Mermaid 图表

【iPhone 和 iPad 版】
• 在 iPhone 上，收件箱、“我的议题”、你的项目和搜索各有一个标签页；在 iPad 上则有边栏和支持拖放的看板
• 向右轻扫可将议题标记为完成，向左轻扫可将其分配给自己或删除
• 按住议题即可更改其状态、优先级、负责人、标签、里程碑、父议题或阻塞关系，或将其拖到新位置
• 里程碑和路线图：在 iPhone 上显示为列表，在 iPad 上显示为时间线
• 在 iPad 上连接键盘后，可使用与 Mac 版相同的快捷键

【会提醒你的截止日期】
• 为议题设定截止日期：明天、周五、日历中的某一天，或直接输入“3 天后”
• 截止当天，你的 Mac、iPhone 和 iPad 会提醒你，并提供按钮让你开始处理议题、将其标记为完成或改到明天
• 该日期就是 GitHub 上项目的“Due date”字段，因此你的团队也能看到

【快速可靠】
• 每项更改都会立即显示，并在后台发送到 GitHub
• 可离线使用：更改会先等待，并在你恢复联网后发送
• 谨慎对待他人的工作：当其他人更改了同一段文字时，不会覆盖任何内容

【隐私】
• 无需注册，没有服务器，没有跟踪。你的登录信息保存在你的钥匙串中，只会发送给 GitHub。
• 已在一台设备上登录？其他设备会通过 iCloud 钥匙串自动登录。

支持英语、德语、法语、西班牙语、葡萄牙语、俄语、日语、韩语和中文，跟随你设备的语言。

无需账户即可试用：“使用示例数据体验”会打开两个示例项目。

Issues 是开源软件：github.com/lukaskaibel/issues-for-github
Issues 与 GitHub 无关联，也未获得 GitHub 的认可。
