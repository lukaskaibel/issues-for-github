Issues 是一款快速的原生 App，让你在 Mac、iPhone 和 iPad 上使用 GitHub Issues 和 GitHub Projects。它界面清爽、操作迅速，而且所有内容都保留在 GitHub 中：不使用此 App 的队友在 github.com 上看到的是同样的议题和看板。

【收件箱】
• 根据 GitHub 的通知，了解与你相关的变化：谁将议题分配给你、提及了你、发表了评论、请求你审查，或关闭了你关注的议题
• 打开一条通知，议题随即呈现，最新动态位于顶部，新评论也会被标出
• 你的到期议题会在当天出现，并附有“开始”“标记为完成”和“改到明天”按钮
• 按一个键或轻扫一下即可标记已读、归档和稍后提醒；已读和归档状态与 github.com 保持一致
• 设为稍后提醒和未读的通知会通过 iCloud 在你的所有设备间保持同步

【Mac 版】
• 每个项目都可以显示为看板或列表，“我的议题”则汇集了分配给你的所有议题
• 显示你的仓库中的每个议题，包括不在任何看板上的议题，点按一下即可将其放到看板上
• 在看板或列表中将议题拖到新位置，并调整列：添加、重新命名、更改颜色和重新排序
• 键盘优先：J 和 K 在议题间移动，S、P、A 和 L 分别更改状态、优先级、负责人和标签，D 设置截止日期，⌘K 打开命令面板，处理其他一切操作
• 选择多个议题，一次性更改
• 按空格键快速查看议题，或打开议题，旁边即是其属性、子议题和评论
• 子议题和阻塞关系：将任意议题放到另一个议题之下，将现有议题添加为子议题，并标记哪个议题阻塞了哪个
• 描述的呈现方式与 GitHub 一致，支持表格、可勾选的清单和 Mermaid 图表
• 后退和前进的用法与浏览器相同

【iPhone 版】
• 收件箱是第一个标签页，并显示未读通知的数量
• “我的议题”汇集了分配给你的所有议题，并按状态分组
• 每个项目和仓库都以列表显示，分组可以折叠
• 向右轻扫可将议题标记为完成，向左轻扫可将其分配给自己或删除
• 按住议题即可更改其状态、优先级、负责人、标签、父议题或阻塞关系，或将其拖到新位置
• 按标题或编号搜索所有项目
• 描述中的表格、清单和 Mermaid 图表，呈现方式与 GitHub 一致

【iPad 版】
• 边栏中列出你的所有项目和仓库，看板支持拖放
• 收件箱旁边即是议题，就像“邮件”一样
• 议题打开时，其属性就在旁边，与 Mac 版相同
• 连接键盘时：J 和 K 用于移动，S、P、A 和 L 用于更改议题，⌘N 新建议题

【会提醒你的截止日期】
• 为议题设定截止日期：明天、周五、下周、日历中的某一天，或直接输入“3天后”
• 卡片和列表会显示截止日期，当天显示为橙色，过期后显示为红色
• 截止当天，你的 Mac、iPhone 和 iPad 会提醒你，并提供按钮让你开始处理议题、将其标记为完成或改到明天
• 该日期就是 GitHub 上项目的“Due date”字段，因此你的团队也能看到

【快速可靠】
• 每项更改都会立即显示，并在后台发送到 GitHub
• 可离线使用：更改会先等待，并在你恢复联网后发送
• 谨慎对待他人的工作：当其他人更改了同一段文字时，不会覆盖任何内容

【隐私】
• 无需注册，没有服务器，没有跟踪。你的登录信息保存在你的钥匙串中，只会发送给 GitHub。
• 已在一台设备上登录？其他设备会通过 iCloud 钥匙串自动登录。

支持英语、德语、法语、西班牙语、葡萄牙语、俄语、日语、韩语和中文，跟随你设备的语言。

无需账户即可试用：“使用示例数据体验”会打开两个示例项目。

Issues 是开源软件：github.com/lukaskaibel/issues-for-github
Issues 与 GitHub 无关联，也未获得 GitHub 的认可。
