你的操作都能撤销，每个议题都会显示 GitHub 的议题类型，看板也登陆了 iPhone。

• 撤销和重做：⌘Z 撤销你上一次的更改，⇧⌘Z 再将它恢复，适用于 Mac 和连接了键盘的 iPad；状态、字段、标签、父议题、卡片在看板上的位置都能撤销，一次更改多个选中的议题后也可以
• 议题类型：Bug、Feature、Task 以及你的组织自己的类型会以各自的颜色显示在卡片、列表行和议题页面上；点按类型或按 T 即可更改
• 议题所在的每个项目的字段都直接显示在它的详细信息中，并可使用“添加到项目”
• 将一个议题拖放到另一个议题上，即可使它成为子议题：适用于 Mac 上的看板和列表，以及 iPhone 和 iPad 上的看板
• 在选取状态的地方即可直接创建状态，并为它设定图标和颜色
• 点按一下或按 ⇧C 即可将议题放入某个迭代，当前迭代和下一个迭代都有标记
• 描述或评论中指向其他议题的链接会直接在 App 中打开
• “我的议题”以概览形式呈现，你参与的每个项目各有一张卡片
• “所有议题”取代了“仓库”：项目的议题与不在任何看板上的议题汇集一处，也可以显示为看板
• 时间线可以缩放，拖动横条即可移动议题的日期
• 在 Mac 上，“搜索”位于边栏顶部，“新建议题”位于工具栏中，“快速查看”显示在窗口中央；在 Force Touch 触控板上用力点按即可打开它
• iPhone 上的看板：一次显示一列，上方的横栏列出所有列及各列的议题数；按住卡片，再将它放到横栏中的某一列上
• 项目优先：iPhone 不再使用标签栏，打开后会回到你上次停留的位置；置顶可将视图、里程碑或路线图放到收件箱和“我的议题”旁边
• 在 iPad 上，边栏列出所有项目，当前打开的项目下方会显示它的视图和里程碑
• 更清爽的看板：卡片置于灰色背景上，不再有边框；标签显示为圆点加名称；颜色只留给需要你关注的内容
• 子议题的子议题以树状结构展开；被阻塞的议题会标明阻塞它的议题，旗标上显示为 #364 这样的编号
• 选择多个子议题并一次性更改；选择器会列出你最近选过的内容
• 隐藏你用不到的看板列或项目，仅在你的设备上生效
• Markdown 在你编写时就以 GitHub 的样式呈现，支持提示框、公式、脚注和图片；输入 ** 即开始粗体，输入 ## 即开始小标题
• 修复：新建议题时总能找到仓库；在 GitHub 上更改了颜色的标签，在 App 中也会随之更新；以及许多小问题
