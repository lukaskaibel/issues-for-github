迄今为止最大的一次更新：用里程碑、史诗和路线图做规划，打开项目在 GitHub 上的视图，以 9 种语言使用 Issues，还换上了与“邮件”和“备忘录”一脉相承的全新外观。

• 里程碑：边栏中显示看板接下来的几个里程碑，每个都列出其议题、完成进度和截止日期。完成一个里程碑时，可将未完成的议题移到下一个
• 史诗：由子议题组成的议题。在看板上，史诗的议题会集中在它的名称下；拖动名称即可将它们整体移动
• 路线图：你的史诗以横条形式显示在里程碑上，可按月或按季度查看。拖动横条，即可将史诗及其议题移到另一个里程碑
• 边栏中列出你的项目在 GitHub 上的视图，可显示为看板或列表，筛选条件以胶囊形式呈现。按里程碑或父议题分组时，视图会显示每组的进度；当前迭代的视图会显示剩余天数；路线图视图则显示为时间线
• iPhone 和 iPad 上同样有里程碑、视图和路线图；路线图在 iPhone 上显示为列表，在 iPad 上显示为时间线
• 全新外观：在 Mac 上，窗口布局与“邮件”和“备忘录”一致，采用 Liquid Glass，议题旁有检查器，右键菜单带有搜索栏。在 iPhone 和 iPad 上，议题的属性以玻璃质感的胶囊显示，评论以对话形式呈现
• 重新打磨的 App 图标：另有石墨或靛蓝底色可选；还可以为每个项目选择你喜欢的图标
• 9 种语言：英语、德语、法语、西班牙语、葡萄牙语、俄语、日语、韩语和中文，跟随你设备的语言
• 收件箱：你的 GitHub 通知，议题就在旁边。用按键或轻扫即可标记为已读、归档或稍后提醒，并与 github.com 和你的其他设备保持一致
• 截止日期与提醒：选择日期或直接输入，例如“3 天后”，当天你的 Mac、iPhone 和 iPad 会提醒你
• 子议题紧挨在父议题下方；完成最后一个子议题后，父议题也随之完成。还可以标记哪个议题阻塞了哪个
• 每个议题，无论是否在看板上：边栏中显示你的仓库，不在任何看板上的议题，点按一下即可放到看板上
• 描述的呈现方式与 GitHub 一致：表格、可勾选的清单、代码和 Mermaid 图表
• 像使用笔记 App 一样编写 Markdown：粗体、斜体和代码格式可以打开或关闭，换行时列表会自动延续；在 iPhone 和 iPad 上，键盘上方的工具栏会根据插入点所在的位置显示相应的按钮
• 更少点按：选择状态、负责人或标签后，选择器会立即关闭
• 修复了将 iPad 转到横向时 App 可能意外退出的问题；此外，在 Mac 上用双指轻扫时不会再意外后退
